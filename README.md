# 100 Days of JavaScript

A daily JavaScript challenge repository focused on consistent practice through small, practical problems.

## Goals

- Build strong JavaScript problem-solving skills
- Practice writing clean, readable solutions
- Stay consistent by solving one challenge per day

## Repository Structure

Each day lives in its own folder:

```text
day-001/
  README.md      # Problem statement and hints
  solution.js    # Working solution for the day
```

As new days are added, follow the same pattern (`day-002`, `day-003`, ...).

## How to Run a Solution

From the repository root, run a day's solution with Node.js:

```bash
node day-001/solution.js
```

## Challenge Format

Each day should include:

1. **Problem statement** in `README.md`
2. **Constraints and examples**
3. **Solution implementation** in `solution.js`

## Adding a New Day

1. Create a new folder (for example, `day-002`)
2. Add a `README.md` with the challenge description
3. Add a `solution.js` with your solution and sample test output
4. Update the **Current Progress** table in the root `README.md`

## Contribution Notes

- Keep naming consistent with `day-XXX`
- Prefer simple, readable solutions first
- Include representative test cases in each `solution.js`
